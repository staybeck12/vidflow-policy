Privacy Policy

Last updated: May 23, 2026

1. Overview

VidFlow AI ("the App") is a personal-use application developed by staybeck12. This Privacy Policy explains how the App handles information in connection with its use of the TikTok API and Instagram API.

2. Data Collection

The App does not collect, store, or share any personal data from users or third parties. All operations are performed locally on the developer's personal device.

3. Use of TikTok API

The App uses the TikTok Content Posting API solely to publish video content to the developer's own TikTok account. No TikTok user data is accessed, collected, or stored beyond what is strictly necessary for the posting operation.

4. Use of Instagram API

The App uses the Instagram Graph API solely to publish video content (Reels) to the developer's own Instagram account. No Instagram user data is accessed, collected, or stored beyond what is strictly necessary for the posting operation.

5. Third-Party Sharing

The App does not sell, trade, or share any data with third parties.

6. Data Security

All API tokens and credentials are stored locally on the developer's personal device and are never transmitted to any external server.

7. Contact

For any questions regarding this Privacy Policy, contact: staybeck12 via GitHub at github.com/staybeck12
